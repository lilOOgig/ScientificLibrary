# Лабораторная работа №1

**Тема:** Классы и объекты  
**Выполнил:** Виршич Елизавета  
**Группа:** 550501  

---

## Цель работы
Создание консольного приложения «Научная библиотека» для управления архивом библиотеки и книгами с использованием ключевых принципов ООП, безопасного ввода данных и контроля версий через Git.

---

## Структура проекта
* `Publication.h` — класс сущности «Публикация» (название, автор, тип, год издания, наличие).
* `ScientificLibrary.h` — класс сущности «Научная библиотека» (название, максимальная вместимость, объекты).
* `ScientificLibrary.cpp` — класс-менеджер для логики и управления списком объектов.
* `first_lab.cpp` — меню пользователя, обработчики команд и функция валидации ввода.

---

## Основной функционал
1. **Отображение всего каталога:** ввод информации о всех книгах в библиотеке.
2. **Выдача книги читателю: / Прием книги обратно:** меняет статус наличия книги в библиотеке.
3. **Поиск книги по автору:**отображает все книги выбранного автора из каталога.
4. **Изменение года издания книги** сохраняет новый введенный год издания для книги.
5. **Защита от ошибок ввода:** устойчивость к вводу некорректных символов (букв, пробелов и спецсимволов).

# Лабораторная работа №2

**Тема:** Дружественные функции, перегрузка функций и операторов  
**Выполнил:** Виршич Елизавета  
**Группа:** 550501  

---

## Цель работы
Расширение программной системы «Научная библиотека» механизмами перегрузки операторов C++ (сравнения, ввода-вывода, управления коллекциями) и использования дружественных функций (`friend`) для работы с закрытыми данными классов.

---

## Структура проекта
* `Publication.h` / `Publication.cpp` — класс «Публикация» с перегруженными операторами сравнения (`==`, `!=` по названию/автору; `<`, `>`, `<=`, `>=` по году издания) и потокового ввода-вывода (`<<`, `>>`).
* `ScientificLibrary.h` / `ScientificLibrary.cpp` — класс-менеджер с перегруженными операторами модификации коллекций `+=` (добавление издания) и `-=` (удаление/списание издания).
* `main.cpp` — консольное интерактивное меню и обработка команд пользователя.

---

## Основной функционал
1. **Сравнение объектов:** операторы равенства по названию и автору (`==`, `!=`) и сравнения по году издания (`<`, `>`, `<=`, `>=`).
2. **Потоковый ввод-вывод:** считывание публикаций из потока ввода через `std::cin >>` (с использованием `friend`-функции) и удобный печатный вывод через `std::cout <<`.
3. **Управление коллекцией через операторы:** добавление публикаций в фонд библиотеки через оператор `+=` и списание через `-=`.
4. **Защита и бизнес-ограничения:** проверка лимитов вместимости библиотеки, блокировка списания выданных читателям книг и поддержание целостности данных.

---

# Лабораторная работа №3

**Тема:** Наследование классов  
**Выполнил:** Мацкевич Кирилл  
**Группа:** 550501  

---

## Цель работы
Расширение программной системы «Научная библиотека» иерархией классов: выделение базовой сущности «Публикация» (`Publication`) и пяти специализированных сущностей (`Book`, `Article`, `Monograph`, `Journal`, `Conference`) с общими характеристиками и специфическими свойствами, использование полиморфного наследования для исключения дублирования кода и прохождения статического анализа.

---

## Структура проекта
- `Publication.h` / `Publication.cpp` — базовый абстрактный класс «Публикация» с общими характеристиками (название, автор, год издания, статус выдачи), защищёнными методами ввода и единой проверкой корректности года.
- `Book.h` / `Book.cpp` — производный класс «Книга» (специфическое поле — количество страниц).
- `Article.h` / `Article.cpp` — производный класс «Статья» (специфические поля — название научного журнала и номер выпуска).
- `Monograph.h` / `Monograph.cpp` — производный класс «Монография» (специфические поля — ISBN и тираж).
- `Journal.h` / `Journal.cpp` — производный класс «Журнал» (специфические поля — номер тома и издательство).
- `Conference.h` / `Conference.cpp` — производный класс «Конференция» (специфические поля — название конференции и место проведения).
- `ScientificLibrary.h` / `ScientificLibrary.cpp` — класс-менеджер (библиотека), хранящий публикации разных типов в общей полиморфной коллекции (`std::shared_ptr<Publication>`).
- `main.cpp` — консольное меню управления фондом библиотеки, демонстрация перегруженных операторов и полиморфизма.

---

## Основной функционал
1. **Иерархия классов:** публичное наследование классов `Book`, `Article`, `Monograph`, `Journal` и `Conference` от абстрактного базового класса `Publication`; общие данные и методы описаны только в базовом классе, производные добавляют лишь специфические свойства.
2. **Конструкторы и доступ к полям:** конструкторы по умолчанию и с параметрами, передача общих параметров конструктору базового класса через список инициализации, методы доступа к специфическим полям.
3. **Переопределение методов:** чисто виртуальный метод `getType()`, а также виртуальные `printSpecific()` и `readSpecific()` переопределены в производных классах для реализации полиморфного поведения.
4. **Повторное использование кода:** операторы сравнения (`==`, `<`, `>` и др.) и операторы ввода-вывода (`<<`, `>>`) реализованы в базовом классе и корректно работают для всех типов публикаций; оператор `>>` использует защищённый метод базового класса `readBase()` и запрашивает через `readSpecific()` только специфические поля, что исключает дублирование кода для SonarCloud.
5. **Ограничения предметной области:** год издания должен быть положительным числом, защита от добавления дубликатов изданий в фонд, контроль превышения максимальной вместимости библиотеки и проверка статуса выдачи книги читателю.
